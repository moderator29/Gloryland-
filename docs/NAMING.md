# Rigel naming system

Rigel is a blue supergiant in Orion, historically a navigation star. Names
across the product come from navigation, light and precision instruments. They
should sound like parts of an instrument, not like features in a dashboard.

## Rules

1. No name should describe a widget. Name the job, not the control.
2. One word wherever possible. Two only when the pair is inseparable.
3. Never reuse a name across two concepts. Signal is the channel, Insight is
   the derivation, and they are not interchangeable.
4. Copy never uses em dash characters.
